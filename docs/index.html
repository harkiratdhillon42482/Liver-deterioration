How It Works — Step by Step

1
Train on MIMIC-III (2001-2012)
3,382 liver patients, 5,505 admissions (ICU only). For each patient with 2+ admissions: extract 77 features from admission N, predict deterioration at admission N+1. XGBoost trained on 1,462 pairs. AUC 0.853.
2
Apply to MIMIC-IV (2008-2019)
2,164 liver patients (ICU + ward). Extract same 77 features. Feed into trained MIMIC-III model. Get risk score 0-1 per admission. Model has never seen MIMIC-IV data — true out-of-sample test.
3
Verify Against Reality
For each scored admission N, query Postgres MIMICIV for actual N+1 outcomes: MELD delta, hepatorenal, encephalopathy, death. Compare prediction vs ground truth. Compute AUC 0.712.
4
Option C Labels
Deterioration = ANY of: MELD rises ≥5pts, MELD≥30, hepatorenal syndrome, encephalopathy, bleeding varices, or death. Composite label captures full clinical spectrum of transplant-level acuity.
5
77 Features Engineered
Demographics, MELD-Na (peak bili+creat, last INR+sodium), Ghandian lab history summaries, MELD trajectory (slope, acceleration, consecutive increases), medication context (chronic oral vs acute IV split), utilization patterns.
6
Dual Architecture Validated
Same pipeline runs on PostgreSQL (AUC 0.853) and YottaDB MUMPS ^PHD globals (AUC 0.820). MUMPS is 3.4x faster (23.5s vs 79s). CIs overlap — statistically equivalent quality.
